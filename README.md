am # Task-Tracker

A Flask-based web application for managing tasks and tracking time. The Task Tracker allows users to create, view, and organize tasks with priority levels, while also providing time tracking capabilities.

## Features

- **Task Management**: Create, view, and manage tasks with a clean, intuitive web interface
- **Priority Levels**: Assign priority levels (Low, Medium, High) to tasks for better organization
- **Task Sorting**: Sort tasks by priority to focus on what matters most
- **Time Tracking**: Track and log time spent on tasks
- **RESTful API**: Full API endpoints for programmatic access to tasks and time tracking
- **Persistent Storage**: SQLite database for reliable data persistence
- **Responsive UI**: User-friendly HTML templates for easy task and time management

## Technology Stack

- **Backend**: Flask (Python web framework)
- **Database**: SQLAlchemy ORM with SQLite
- **Frontend**: HTML templates with CSS styling
- **Testing**: Pytest, Playwright, Robot Framework, Selenium
